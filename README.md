# العلوم الفيزيائية والتكنولوجيا — التعليم المتوسط (1AM–3AM)

تطبيق تعليمي يعمل في المتصفّح ويمكن تثبيته على الهاتف، ثم يعمل **دون اتصال بالإنترنت**:
دروس مفصّلة تتبع فهرس الكتاب المدرسي (الجيل الثاني)، تشبيهات، طرائق، تمارين محلولة،
محاكيات، مخبر افتراضي، مولّدات تمارين، ونماذج اختبارات مع تصحيحها.

**الرابط:** `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## التثبيت على الهاتف
- **أندرويد (Chrome):** افتح الرابط، ثم اضغط زرّ «📲 تثبيت» في أعلى التطبيق إن ظهر،
  أو قائمة ⋮ ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- **آيفون / آيباد (Safari):** زرّ المشاركة ← «إضافة إلى الشاشة الرئيسية» ← «إضافة».
- افتح التطبيق مرّة واحدة وأنت متّصل؛ بعدها يعمل دون إنترنت.
